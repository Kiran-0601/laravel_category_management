# Laravel Category Management  

This project is a Laravel-based category management system that allows users to manage parent and subcategories efficiently.  

## 🚀 Getting Started  

Follow these steps to set up and run the project on your local environment.  

### **1️⃣ Clone the Repository**  
Open your terminal and run:  
```sh
git clone https://github.com/Kiran-0601/laravel_category_management.git
cd laravel_category_management
add database creds in env file
php artisan migrate
php artisan serve
